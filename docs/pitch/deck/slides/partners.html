Two partners: NVIDIA chemistry, Formlabs fabrication

NVIDIA ALCHEMI gives us computed molecular evidence: over a thousand GPU runs, cached so the demo runs offline. It finds lactic the stronger acid, by four pKa units against one in experiment, and it moves toward experiment as we add water. That only bounds the model’s acid terms. The model is built from published sourdough kinetics, Gänzle 1998 and Rosso 1993, with every parameter cited or labelled an assumption. It takes the recipe, the temperature schedule and the starter’s state, and predicts pH, acids, gas, rise and overproofing. Formlabs makes the prediction physical: the PreForm API prepares both crumb specimens for print, and a person presses print.
